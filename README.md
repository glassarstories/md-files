# md-files

Робочий репозиторій документації для бізнесу Butterflarium.

## Розділи

- [`google-ads/`](google-ads/README.md) — ведення та аналіз рекламного кабінету Google Ads: реєстр кампаній, журнал аналізів, чекліст запуску нових РК, журнал змін, налаштування акаунта, технічні проблеми, KPI та правила прийняття рішень.
- [`klaviyo/`](klaviyo/README.md) — створення та налаштування email-маркетингу через Klaviyo: чекліст запуску, доставлюваність (DNS, прогрів), сегменти, форми підписки, флоу-автоматизації, календар розсилок, журнали кампаній і A/B-тестів, KPI, технічні проблеми.

Кожен розділ має власний `README.md` з описом того, які файли всередині і як ними користуватись.
