# Журнал кампаній (разових розсилок)

> Запис про кожну відправлену кампанію: що, кому, з яким результатом і який висновок. Мета — накопичувати знання "що працює саме для нашої аудиторії", а не орієнтуватись лише на загальні бенчмарки. Новий запис — зверху.

## Шаблон запису

```

**Тип:** [Історія / Новинка / Продаж / Сезон / UGC / Gift guide]

**Отримувачів:** [N]
**Тема:** [subject line]  |  **Preheader:** [ ]
**Оффер:** [немає / код / % / безкоштовна доставка]
```
