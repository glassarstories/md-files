# Контент-гайд: тон, структура, дизайн

> Правила для всіх листів (флоу і кампаній), щоб бренд звучав однаково. Тон узгоджувати з описами товарів на сайті (Specimen Tag, точні назви видів).

## Тон голосу (Brand voice)

- **Англійська (US)**, тепла, захоплена природою, з дрібкою "натуралістської" точності — як листи від майстра-ентомолога, а не від корпорації
- Говоримо про **світло, колір, вид, ручну роботу**: "When the morning sun hits the wings…"
- Точні назви видів (common + латинська, напр. *Morpho peleides*) — це підкреслює експертність і цінність
- Без агресивних CAPS, "!!!", фейкових дедлайнів і "BUY NOW"
- Без неперевірених тверджень ("the best in the world")
- Підпис: [ім'я засновника/майстра або "The Butterflarium Studio"]

## Структура листа

1. **Preheader** — продовжує тему, не повторює її
2. **Хедер** — логотип (клік → головна)
3. **Hero** — одне сильне фото (метелик на світлі/в інтер'єрі) + заголовок
4. **Короткий текст** — 2–4 речення, одна ідея на лист
5. **Головний CTA** — кнопка (не картинка-кнопка), вище першого "згину" на мобільному
6. **Товари / історія / відгук** — підтримка ідеї
7. **Футер** — адреса, відписка, manage preferences, соцмережі, "why you're receiving this"

## Subject line та preheader

- Довжина теми: ~30–50 символів (обрізається на мобільному)
- Емодзі — помірно, тематичні (🦋 🌙 ✨), не в кожній темі
- Персоналізація (`{{ first_name }}`) — лише з fallback
- Без спам-тригерів типу "FREE!!!", "$$$", "Act now"
- Тестувати теми через A/B → [`ab-testing-log.md`](ab-testing-log.md)

## Дизайн

- Ширина шаблону: 600px
- Співвідношення тексту й зображень: не робити лист однією картинкою (спам-фільтри + недоступність)
- Усі зображення — з **alt-текстом**; стиснуті (< 200–300 KB кожне)
- Шрифти: [брендовий] з fallback на Arial/Georgia
- Кольори бренду: [HEX], фон [HEX], кнопки [HEX] — достатній контраст
- Dark mode: перевіряти, що логотип не "зникає" (прозорий PNG з обведенням або окрема версія)
- Мобільна перевірка — обов'язкова перед кожною відправкою

## Персоналізація і динамічні блоки

| Що | Синтаксис / блок | Fallback |
|---|---|---|
| Ім'я | `{{ first_name\|default:'friend' }}` | "friend" / "there" |
| Товари з кошика/чекауту | Dynamic table block / `event.extra.line_items` | — |
| Переглянутий товар | `{{ event.Name }}`, `{{ event.URL }}`, `{{ event.ImageURL }}` | — |
| Рекомендації | Product block → Recommended / Popular / з колекції | — |
| Умовні блоки | Show/hide за сегментом/властивістю (напр. інтерес "Moths") | загальний блок |

## UTM-мітки

Klaviyo може автоматично додавати UTM (Settings → UTM Tracking). Наш стандарт:

| Параметр | Кампанії | Флоу |
|---|---|---|
| `utm_source` | `klaviyo` | `klaviyo` |
| `utm_medium` | `email` | `email` |
| `utm_campaign` | `{назва_кампанії}_{РРРРММДД}` | `flow_{назва_флоу}` |
| `utm_content` | `{назва_блоку/кнопки}` (опційно) | `{номер_листа}` |

## Юридичні вимоги (CAN-SPAM, США)

- Чіткий відправник (From) і правдива тема
- Фізична поштова адреса у футері
- Робоче посилання відписки, обробка — без затримок (Klaviyo — автоматично)
- Не надсилати маркетинг тим, хто не давав згоди (покупці без чекбокса — лише транзакційні листи)
- Якщо будуть підписники з ЄС/UK — додатково GDPR (явна згода, double opt-in бажано)
