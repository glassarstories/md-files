# KPI та бенчмарки email-маркетингу

> Визначення метрик, орієнтири по e-commerce і наші цілі. Галузеві цифри — лише стартова точка; через 2–3 місяці власні середні важливіші. Klaviyo має вбудовані бенчмарки (Analytics → Benchmarks) порівняно з подібними брендами — звіряти з ними.

## Основні метрики

| Метрика | Формула | Орієнтир (e-commerce)* | Наша ціль |
|---|---|---|---|
| Open rate | Унікальні відкриття / Доставлені | ~35–45% (завищено Apple MPP — ненадійний) | [ ] |
| Click rate | Унікальні кліки / Доставлені | кампанії ~1–2%; флоу — вище | [ ] |
| Placed order rate (conversion) | Замовлення / Доставлені | кампанії ~0.05–0.15%; Abandoned Checkout ~3%+ | [ ] |
| **Revenue per recipient (RPR)** | Виручка / Доставлені | кампанії ~$0.05–0.20; Welcome ~$1–3; Abandoned Checkout ~$3+ (сильно залежить від AOV) | [ ] |
| Unsubscribe rate | Відписки / Доставлені | < 0.3% | < 0.3% |
| Spam complaint rate | Скарги / Доставлені | < 0.1% (жорстка межа Gmail — 0.3%) | < 0.05% |
| Bounce rate | Bounce / Відправлені | < 1% | < 1% |
| Submit rate форми (popup) | Сабміти / Перегляди | ~2–5%, сильні форми 8%+ | [ ] |
| Ріст бази | Нові підписники − відписки − suppressed за місяць | — | [ ] |
| **Частка email у виручці магазину** | Attributed revenue Klaviyo / Загальна виручка Shopify | зрілий акаунт: 20–30%+ | [ ] |
| Частка флоу у виручці email | Revenue флоу / Revenue email | 40–60%+ | [ ] |

*Орієнтири узагальнені й наближені — використовувати лише як точку відліку, не як гарантію.

## Головна метрика — RPR, а не open rate

- Open rate після Apple Mail Privacy Protection (2021) штучно завищений → порівнювати теми листів через open rate можна лише всередині A/B-тесту, і бажано підтверджувати кліками.
- **RPR** об'єднує все (доставлення → відкриття → клік → покупка → чек) і дозволяє порівнювати листи з різною аудиторією.
- Click rate — основний сигнал залученості контенту.

## Економіка email для нашого магазину

```
AOV = $155, валова маржа = 25% → валовий прибуток із замовлення ≈ $38.75

Знижка 15% на перше замовлення = $23.25 → залишається ≈ $15.50 прибутку (~40% від маржі)
Фіксовані $10 від $100 = $10 → залишається ≈ $28.75 (~74% від маржі)
```

- Висновок: для нашої маржі знижки — дорогий інструмент; пріоритет — **флоу без знижок**, цінність і соціальні докази; знижки — точково (Welcome, BFCM, Win-back).

## Як інтерпретувати відхилення

| Сигнал | Ймовірна проблема |
|---|---|
| Open rate різко впав (особливо на Gmail) | Проблема доставлюваності — листи пішли в спам. Див. [`deliverability.md`](deliverability.md) |
| Високий open, низький click | Тема обіцяє одне, лист — інше; слабкий CTA; немає чіткого "наступного кроку" |
| Високий click, низька конверсія | Посадкова/товар не відповідають листу, ціна/доставка "лякають", проблема на сайті |
| Ріст відписок | Занадто часто, нерелевантний сегмент, однотипні продажні листи |
| Ріст скарг на спам | Імпорт без згоди, відправка на неактивних, незрозуміло, хто відправник |
| Флоу Abandoned Checkout з низьким RPR | Затримка занадто велика/мала, не працює динамічний блок, не те посилання на чекаут |
| Email-частка виручки < 10% через 3+ міс. | Немає ключових флоу, база не росте (слабка форма), рідкі розсилки |

## Правила прийняття рішень

- Не робити висновків по кампанії на вибірці < **1 000 доставлень** або раніше ніж через **3–5 днів** після відправки (замовлення "доїжджають").
- Флоу оцінювати за **30+ днів** або **100+ отримувачів**, що настане пізніше.
- A/B-тест — лише одна змінна за раз, переможця визначати за click rate / RPR, не лише open rate.
- Якщо spam complaint rate > 0.1% у будь-якій кампанії — наступна розсилка лише на Engaged 30/60, розбір причини обов'язковий.
