# Технічні проблеми — довідник вирішення

> Швидкий довідник для технічних питань Klaviyo. Нові кейси дописувати в "Історію реальних кейсів" з датою і рішенням.

## Листи потрапляють у спам / Promotions

- **Перевірити автентифікацію:** Settings → Domains — статус брендованого домену *Verified*; SPF/DKIM/DMARC — див. [`deliverability.md`](deliverability.md)
- **Перевірити, кому відправляли:** розсилка на всю базу/неактивних → звузити до Engaged 30/60, повторити прогрів
- **Перевірити контент:** лист однією картинкою, скорочувачі посилань (bit.ly), спам-слова в темі, дуже важкі зображення
- **Google Postmaster Tools:** репутація домену Low/Bad → кілька тижнів лише найактивніші сегменти
- **Вкладка Promotions у Gmail** — нормально для маркетингових листів, це не спам; боротися не варто

## Флоу не спрацьовує / ніхто не входить у флоу

- Статус флоу **Live**? (не Draft/Manual) — і статус кожного листа теж Live
- Чи надходить метрика-тригер: Analytics → Metrics → [метрика] → Activity feed. Якщо ні — проблема інтеграції/трекінгу
- **Flow filters** занадто жорсткі (напр. "Placed Order zero times **over all time**" відсікає всіх покупців)
- Людина отримала інший лист нещодавно → **Smart Sending** пропустив (див. звіт флоу: "Skipped")
- Профіль не має згоди на email marketing → маркетингові листи пропускаються
- Флоу запущено пізніше події — флоу не "заднім числом", лише для нових подій (крім опції backfill при створенні)

## Browse Abandonment / Added to Cart не має подій

- Klaviyo **app embed** у темі Shopify увімкнено? (Online Store → Themes → Customize → App embeds)
- Після зміни/оновлення теми Shopify app embed може вимкнутись — перевірити
- Події `Viewed Product` фіксуються лише для **ідентифікованих** відвідувачів (підписані/клікали з листа/купували) — це нормально, анонімні не трекаються
- Cookie-банер / consent може блокувати скрипт до згоди

## Замовлення / клієнти не синхронізуються зі Shopify

- Integrations → Shopify — статус підключення, остання синхронізація; за потреби reconnect
- Перевірити, що app Klaviyo в Shopify не видалено і доступи (scopes) повні
- Тестове замовлення → перевірити появу `Placed Order` у профілі (може бути затримка кілька хвилин)

## Знижкові коди не працюють

- Унікальні коди: Klaviyo → Coupons, тип *Shopify unique*, — чи відповідає налаштуванню знижки в Shopify (мінімальна сума, товари, термін)
- Пул кодів не вичерпано / коди генеруються
- Код з терміном дії, що минув, у старому листі флоу — оновити

## Динамічні блоки порожні / зламана персоналізація

- Попередній перегляд листа з **реальним профілем і подією** (Preview → вибрати профіль/подію)
- Шлях до поля неправильний (`event.extra.line_items` vs `event.Items`) — подивитись JSON події в Activity feed
- Немає fallback (`|default:'...'`) → у листі "Hi ,"

## Форма не показується

- Статус форми **Live**
- Правила таргетингу: показується лише непідписаним → у тестовому браузері ви вже підписані (тестувати в incognito)
- Обмеження частоти показу (після закриття не показувати N днів)
- App embed Klaviyo в темі вимкнений
- Конфлікт з іншим popup-app

## Різке падіння open rate

- Перевірити розподіл по провайдерах (Gmail vs Yahoo vs Outlook) — падіння в одного = проблема репутації в нього
- Перевірити, чи не змінювався домен відправки/DNS
- Перевірити сегмент — чи не пішла розсилка на ширшу/холоднішу аудиторію

## Акаунт Klaviyo обмежено / на перевірці (compliance review)

- Причина зазвичай: високий bounce/spam після імпорту бази
- Надати Klaviyo пояснення джерела контактів (форма зі згодою), прибрати неякісний імпорт
- Не імпортувати бази без явної згоди
