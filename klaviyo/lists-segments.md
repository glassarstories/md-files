# Списки та сегменти

> Довідник: які списки і сегменти існують, за якими **точними умовами** побудовані і де використовуються. Перед створенням нового сегмента — перевірити, чи такого вже немає.

**Різниця:** *список* — статичний (людина потрапляє туди дією: підписка, імпорт); *сегмент* — динамічний, перераховується автоматично за умовами. Розсилки ведемо по **сегментах**, база росте через **список**.

## Списки

| Назва | Як потрапляють | Opt-in | Використання | Примітки |
|---|---|---|---|---|
| `Newsletter` | Форми на сайті, чекбокс на чекауті Shopify | [single / double] | Головний маркетинговий список, тригер Welcome | |
| `Preview List` / `Seed` | Вручну — внутрішні адреси | — | Тестові відправки | |
| [`Wholesale / B2B`] | [за потреби] | | | |

**Рішення по opt-in:** [single / double] — причина: [напр. single для швидшого росту бази в США, де double opt-in не обов'язковий; double — якщо бачимо багато фейкових/помилкових адрес]

## Сегменти залученості (для таргетингу кампаній)

| Сегмент | Умова (логіка в Klaviyo) | Для чого |
|---|---|---|
| Engaged 30 | Can receive email marketing **AND** (Opened Email ≥1 за 30 днів **OR** Clicked Email ≥1 за 30 днів **OR** Active on Site ≥1 за 30 днів **OR** Added to list за 30 днів) | Прогрів, найважливіші/ризиковані розсилки |
| Engaged 60 | те саме, 60 днів | |
| Engaged 90 | те саме, 90 днів | **Основний сегмент для регулярних кампаній** |
| Engaged 180 | те саме, 180 днів | Великі сезонні розсилки (BFCM, Різдво) |
| Unengaged 180+ | Can receive email **AND** не відкривав/не клікав/не був на сайті 180 днів **AND** у списку > 180 днів | Вхід у Sunset-флоу, виключення з кампаній |

> Через Apple MPP "Opened Email" ненадійний — якщо Engaged-сегменти занадто "роздуті", прибрати Opened з умови для 30/60 і залишити кліки + активність на сайті.

## Сегменти за поведінкою покупки

| Сегмент | Умова | Для чого |
|---|---|---|
| Ніколи не купували | Placed Order = 0 за весь час **AND** can receive email | Оффер на першу покупку, соціальні докази |
| Покупці (всі) | Placed Order ≥ 1 за весь час | Виключення з "першопокупних" офферів, крос-сел |
| Одноразові покупці | Placed Order = 1 за весь час | Мотивація на другу покупку |
| Повторні покупці | Placed Order ≥ 2 за весь час | Лояльність, ранній доступ |
| VIP | [Placed Order ≥ 3 **OR** сума замовлень ≥ $X] | Ексклюзивні колекції, особлива подяка |
| Купили за останні 14 днів | Placed Order ≥1 за 14 днів | Виключати з агресивних продажних кампаній |
| Під ризиком відтоку | Купував, але не купував > [120–180] днів | Win-back |

## Сегменти джерела / демографії

| Сегмент | Умова | Для чого |
|---|---|---|
| Підписались через popup | Added to Newsletter, Method = Klaviyo Form [ID] | Аналіз форм |
| Підписались на чекауті | Source = Shopify checkout | |
| Не з США | Location country ≠ United States | Виключення з офферів, що діють лише в США (доставка) |

## Сегменти для виключення (suppression)

- Купили за останні 14 днів (з продажних розсилок)
- Unengaged 180+ (з регулярних кампаній)
- Внутрішні/тестові адреси (з аналітики)

## Синхронізація з рекламою

| Сегмент | Куди синхронізується | Призначення |
|---|---|---|
| Покупці (всі) | Meta Ads / Google Ads Customer Match | Виключення з prospecting, база для lookalike |
| Engaged 90, не купували | Meta Ads | Ремаркетинг |
