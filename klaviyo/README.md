# Klaviyo — email-маркетинг Butterflarium

Простий набір файлів під три задачі.

| Задача | Що робите ви | Файл |
|---|---|---|
| 🛠 Допомога з налаштуванням кабінету | Надсилаєте скрін і пишете, що треба зробити | [`setup-help.md`](setup-help.md) |
| 🖼 Alt-тексти до фото в розсилці | Надсилаєте фото і пишете, для якого листа | [`alt-texts.md`](alt-texts.md) |
| 📅 Контент-план і воронка | Просите план на місяць, лист або флоу | [`content-plan.md`](content-plan.md) + [`funnel.md`](funnel.md) |

Загальний контекст бренду (хто ми, тон, аудиторія) лежить у [`brand.md`](brand.md). Його використовують усі три задачі.

## Як писати запит

- **Скрін:** "Ось скрін, хочу налаштувати X / не розумію, що тут вибрати"
- **Фото:** "Alt-тексти для цих фото, лист про Halloween / Welcome-лист 1"
- **План:** "Контент-план на листопад" / "Напиши лист 2 з Welcome-воронки"

Після кожної відповіді я дописую результат у відповідний файл, щоб наступного разу не починати з нуля.
