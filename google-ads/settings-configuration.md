## Стратегії ставок — коли яку використовувати

| Стратегія | Коли доречна |
|---|---|
| Manual CPC / Enhanced CPC | Нова кампанія, немає історії конверсій (<15-30 конверсій/міс) |
| Maximize Conversions | Є трохи історії, ціль — максимум конверсій в межах бюджету |
| Target CPA | Стабільний потік конверсій, є чітка цільова CPA |
| Maximize Conversion Value / Target ROAS | Достатньо даних про value конверсій (>30-50 конверсій/міс бажано), ціль — виручка/прибуток |
