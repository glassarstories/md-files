# Чекліст запуску нової кампанії

> Проходити по кроках при кожному запуску нової РК. Не пропускати "Пре-лонч дослідження" навіть якщо здається очевидним — саме тут найчастіше ховаються дорогі помилки.

## 0. Вибір типу кампанії

| Ціль | Рекомендований тип |
|---|---|
| Продажі товарів з каталогу, автоматизація | Performance Max / Shopping |
| Контроль над ключовими словами, намір "хочу купити зараз" | Search |
| Впізнаваність, ретаргетинг з візуалом | Display / Demand Gen |
| Охоплення через відео | YouTube / Demand Gen |

Обраний тип: [ ] Search [ ] Performance Max [ ] Shopping [ ] Display [ ] Demand Gen / YouTube

## 1. Пре-лонч дослідження

- [ ] **Мета кампанії визначена одним реченням** (продати конкретну лінійку / залучити нових клієнтів / повернути покинуті кошики тощо)
- [ ] **Продукт(и)/колекція** для просування визначені, посилання на Shopify додані
- [ ] **Цільова аудиторія** описана (хто, який намір, на якому етапі воронки)
- [ ] **Конкуренти проаналізовані** (хто рекламується на ці запити/аудиторії, які пропозиції)
- [ ] **Ключові слова / теми** зібрані (для Search — з намірами: transactional/commercial), мінус-слова заплановані
- [ ] **Бюджет розрахований**: цільовий CPA × очікувана к-ть конверсій, або % від виручки
- [ ] **Сезонність врахована** (чи не запускаємо проти сильного сезонного спаду/піку без коригувань)

## 2. Налаштування конверсій (перевірити ДО запуску)

- [ ] Conversion tracking працює і тестований (тестова покупка / GA4 DebugView)
- [ ] Enhanced Conversions увімкнені (якщо застосовно)
- [ ] Значення конверсії (value) передається коректно (не 0, не статичне при різних чеках)
- [ ] Атрибуційна модель узгоджена з рештою акаунта

## 3. Структура кампанії

- [ ] Назва кампанії за єдиною конвенцією найменування (напр. `[Тип]_[Ціль]_[Гео]_[Дата]`)
- [ ] Бюджет виставлено (денний/спільний), відповідає розрахунку з п.1
- [ ] Стратегія ставок обрана і обґрунтована:
  - [ ] Maximize Conversions / Conversion Value
  - [ ] Target CPA / Target ROAS (значення: ___, чи є достатньо історичних даних для навчання)
  - [ ] Manual CPC / Enhanced CPC (для нових кампаній без історії)
- [ ] Гео- і мовний таргетинг виставлені коректно (перевірити "Presence" vs "Presence or interest")
- [ ] Розклад показів (ad schedule) налаштований, якщо є бізнес-логіка (напр. підтримка/обробка замовлень лише в певні години)
- [ ] Ad groups / Asset groups структуровані логічно (по темах/продуктах, не звалені в одну купу)
- [ ] Negative keywords (в т.ч. спільні списки) підключені
- [ ] Аудиторії для спостереження/таргетингу додані (ремаркетинг, схожі, за інтересами)

## 4. Оголошення / креативи

- [ ] Мінімум 3 варіанти заголовків/текстів на групу (для А/Б в межах RSA/asset groups)
- [ ] Заклик до дії чіткий і відповідає етапу воронки
- [ ] УТП (унікальна перевага) присутнє в текстах
- [ ] Зображення/відео у потрібних форматах і якості (для PMax/Demand Gen — квадрат, портрет, ландшафт)
- [ ] Landing page відповідає оголошенню (товар в наявності, швидкість завантаження, мобільна версія)
- [ ] Розширення оголошень (sitelinks, callouts, structured snippets, promotion) додані

## 5. Перевірка перед запуском

- [ ] Бюджет і ставки ще раз звірені (немає помилки на порядок, напр. $100 замість $10)
- [ ] Виключені небажані плейсменти/додатки (для Display/PMax — placement exclusions)
- [ ] Правильний часовий пояс акаунта
- [ ] Немає конфлікту/канібалізації з існуючими кампаніями (перевірити `campaigns-registry.md`)

## 6. Запуск і пост-лонч моніторинг

| Коли | Що перевірити |
|---|---|
| День 1 | Кампанія показується (impressions > 0), немає policy-відхилень, витрати відповідають бюджету |
| День 3 | CTR і CPC в межах очікуваного, немає явних "зливів" бюджету на нерелевантні запити/плейсменти |
| Тиждень 1 | Перші конверсії, чи вийшла Smart Bidding стратегія з learning phase, коригування мінус-слів |
| Тиждень 2 | Перше рішення: масштабувати / коригувати / чекати ще (див. `decision-framework.md`) |
| Місяць 1 | Повний аналіз за шаблоном з `campaign-analysis-log.md`, запис у реєстр |

Після запуску — додати рядок у [`campaigns-registry.md`](campaigns-registry.md).
