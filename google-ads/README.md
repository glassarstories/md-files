# Google Ads — робочі файли

Набір md-файлів для ведення та аналізу рекламного кабінету Google Ads для Butterflarium (Shopify-магазин вітражних комах/сувенірів). Файли розраховані на те, що ними користується і людина, і Claude (в майбутніх сесіях) — тому кожен файл одразу дає контекст, без потреби переказувати все заново.

## Файли та коли їх відкривати

| Файл | Коли використовувати |
|---|---|
| [`account-overview.md`](account-overview.md) | Загальний контекст акаунта, бізнесу, цілей, бюджету. Відкривати першим у будь-якій новій розмові про РК. |
| [`campaigns-registry.md`](campaigns-registry.md) | Актуальний список усіх кампаній, що зараз живі/на паузі. Джерело правди "що взагалі є в акаунті". |
| [`campaign-analysis-log.md`](campaign-analysis-log.md) | Журнал глибинних аналізів кампаній — сюди пишемо знімок метрик, висновки та рекомендації кожного разу, коли роблю аналіз "чому це не працює / що покращити". |
| [`new-campaign-playbook.md`](new-campaign-playbook.md) | Чекліст і фреймворк для запуску нової кампанії — від дослідження до пост-лончевого моніторингу. |
| [`campaign-change-requests.md`](campaign-change-requests.md) | Журнал змін/замін існуючих кампаній (реструктуризація, зміна стратегії ставок, заміна кампанії на іншу) з фіксацією "до/після". |
| [`settings-configuration.md`](settings-configuration.md) | Довідник налаштувань акаунта: конверсії, Merchant Center, аудиторії, negative keywords, доступи, білінг. |
| [`troubleshooting-technical.md`](troubleshooting-technical.md) | Технічні питання: відхилення оголошень, проблеми трекінгу, помилки фіда, призупинення акаунта тощо. |
| [`kpi-benchmarks.md`](kpi-benchmarks.md) | Визначення метрик і цільові бенчмарки для ніші — щоб оцінювати "це добре чи погано". |
| [`decision-framework.md`](decision-framework.md) | Правила прийняття рішень: коли масштабувати, коли призупиняти, коли давати кампанії ще шанс. |

## Як користуватись (робочий процес)

1. **Перед будь-яким аналізом** — заповни/онови `account-overview.md` і `campaigns-registry.md` актуальними даними (можна просто вставити скріншот/експорт метрик у запиті — я перенесу суть у файли).
2. **Питання "проаналізуй і порадь щодо існуючих РК"** → дивлюсь `campaigns-registry.md` + `kpi-benchmarks.md` + `decision-framework.md`, результат аналізу фіксую в `campaign-analysis-log.md`.
3. **Питання "хочу запустити нову РК"** → працюємо за `new-campaign-playbook.md`, після запуску — запис у `campaigns-registry.md`.
4. **Питання "замінити/переробити кампанію"** → фіксуємо в `campaign-change-requests.md` (причина, що саме міняємо, очікуваний ефект), після — оновлюємо `campaigns-registry.md`.
5. **Питання по налаштуваннях кабінету** → `settings-configuration.md`.
6. **Технічна проблема (відхилення, трекінг, фід)** → `troubleshooting-technical.md`.

Усі файли — живі документи: не переписуємо історію, а дописуємо нові записи зверху (найновіше — першим), щоб було видно динаміку рішень.
